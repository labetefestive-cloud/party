# party
🎉 Party-themed Link Tree

A festive, animated link tree (bio links page) perfect for sharing all your social media and contact links in one place!

## Features

- 🎊 **Party Theme**: Vibrant purple gradient background with animated confetti
- ✨ **Smooth Animations**: Bouncing avatar, hover effects, and ripple click animations
- 🔗 **Customizable Links**: Easy to update social media and contact links
- 📱 **Responsive Design**: Works beautifully on mobile and desktop
- 🎨 **Professional Code**: Clean, maintainable, and performant implementation

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser or serve it with any web server
3. Customize the links in `index.html` to match your social profiles

## Customization

Edit `index.html` to update:
- Profile name and bio
- Social media links
- Link icons (using emoji)
- Contact information

The color scheme and animations can be modified in `styles.css`.

## Tech Stack

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript (no dependencies!)

Enjoy your party! 🎉
